# 01 · 产品定义

版本：V1.0 ｜ 2026-09-20 ｜ 上级依据：[项目交接书](../PROJECT_HANDOFF.md)

## 产品要解决的问题

趋势报告让工厂理解市场方向；Development Ready 把精选趋势转为一款能被开发部看懂的设计资料，减少对设计意图的反复猜测。用户负责买手判断与最终设计选择，AI 辅助整理、生成和检查，工厂负责工程落实。

产品路径为 Trend Intelligence → Design → Development Ready → Factory Engineering → Sample。设计多视图不等于 3D 工程数据，Ready 不等于 Production Ready。

## 与趋势网站的关系

同一网站、同一内容体系、两档权益。Standard 阅读趋势；Pro 在趋势后进入精选开发专题。独立目录与原型用于保护主站，最终模块嵌入现有离线 HTML，不单独建立 SaaS。

| 权益 | Standard：¥10,000/年（示例） | Pro：¥16,000/年（示例） |
| --- | --- | --- |
| 趋势图、品牌案例、买手解读 | 包含 | 包含 |
| 精选原创开发款 | 不包含 | 包含 |
| 同款多视图、材料、配色、BOM | 不包含 | 包含 |
| Design Intent、Design Lock、开发建议 | 不包含 | 包含 |
| 工程 CAD、新楦新底新跟、纸版制作 | 不包含 | 不包含，由工厂工程落实 |

¥6,000 为两档示例差价。最终定价、更新频率、开发款数量、修改次数和使用条款待确认。讨论中的每月 8–12 款不是已批准合同指标。不是每个趋势都必须生成开发款，优先精选可表达清楚、适合成熟库匹配的方向。

## 三类读者

| 读者 | 阅读任务 | 主要内容 |
| --- | --- | --- |
| 工厂老板/客户 | 快速判断是否值得继续看 | Hero、Snapshot、首版配色、开发优先级 |
| 开发主管 | 理解设计与可调整边界 | 多视图、Product Language、Lock/Flex、材料、结构意图 |
| 版师/采购 | 找到部件、材料和工程接棒事项 | Structure Map、BOM、编号、工厂匹配建议、待确认项 |

5 秒/30 秒是阅读层级设计目标，不是已完成的用户测试结果。

## 我们与工厂的责任

我们提供 Trend、Design、Multi-view、Material、BOM、Design Intent、Development Advice。材料/尺寸可以表达设计目标或建议，但不能把未核实的规格当作已验证生产参数。

工厂匹配成熟楦库、底库、跟库，决定内部结构与加固，开纸版、备料、做面、成型和打样。具体库号、库存、供应商、用量、成本、周期和适配性由工厂确认。用户已说明工厂具备成熟楦库与底库；具体目标工厂的跟库情况待核实。

Design Lock 描述必须保留的鞋头视觉比例、鞋口线、带位/宽度方向、五金视觉尺度、轮廓和材料效果。Factory Adjustable 描述工程实现空间；若调整会改变 Lock，工厂提出方案，由用户复核并记录新版本，不能自行消除设计约束。

## 明确不做

不做全新鞋楦/鞋跟/大底工程、2D 纸版、CAD 生产文件、工厂内部结构工程或生产级参数确认。本期也不建设客户管理、在线支付、报价采购、供应链或自动接单系统。

不承诺 AI 图片一定可生产、资料交付后无需工程开发、一定获得大单。需要新楦新底新跟的款先改款或暂缓，不直接扩大 V1 范围。

## 首个工厂演示包的产品标准

至少包含一款真实、完整且经人工审核的设计资料，以趋势证据讲清“为什么做”，以母图和多视图讲清“做成什么”，以材料/BOM/Lock/Flex/建议讲清“如何交给工厂继续开发”。

交付介质为 Pro 离线 HTML、对应 PDF 和图片资产 ZIP；演示中能对比基础趋势版和高级开发版。同一款所有介质使用一致款号与修订号。图片 ZIP 的范围是本次交付所引用且允许交付的全部图片，不默认为整个历史图库。

本次只建立产品定义。首款、真实素材、数量、目标客户、样品安排和接收方式待确认；不自动发给工厂。
